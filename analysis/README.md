# Sleep-Grant Classification Pipeline

This folder contains a machine-learning pipeline that identifies sleep-related
grants in the 2014–2019 cohort by learning from a large, high-quality labelled
dataset derived from the 2020–2026 cohort.

---

## Background and approach

The original 2020–2026 grants (~13,000 total) were screened using a two-step
process:

1. **Keyword filter** — every grant was checked against a list of sleep-related
   keywords. Grants matching no keywords were ruled out as confirmed non-sleep.
2. **Manual review** — the ~197 grants that matched at least one keyword were
   individually reviewed by a human expert:
   - 74 confirmed **sleep-related** (true positives)
   - 123 confirmed **not sleep-related** despite the keyword match (true negatives)

The 2014–2019 grants (~11,400) were added later and have **never been
keyword-screened or manually reviewed** — these are the grants we need to score.

### Why this is a strong ML problem

Because every 2020–2026 grant is now labelled (either explicitly by the
reviewer, or implicitly by the keyword filter), we have:

| Label | Count |
|---|---|
| Sleep (positive) | 74 |
| Non-sleep (negative, confirmed) | ~12,900 |

This is a large, high-quality training set. The class imbalance (~1:175) looks
extreme, but logistic regression with `class_weight='balanced'` handles this
correctly and the goal is **ranking** (not a hard yes/no decision), so
precision-recall performance is what matters.

---

## How it works (plain English)

1. **Every grant summary is converted into 384 numbers** — a "semantic
   fingerprint" that captures what the text *means*, not just which words it
   uses. Two summaries about sleep will have similar fingerprints even if they
   use different vocabulary.

2. **A logistic regression model learns** which fingerprints belong to sleep
   grants vs non-sleep grants, using all ~13,000 labelled 2020–2026 grants.

3. **The model scores every 2014–2019 grant** with a probability between 0
   (definitely not sleep) and 1 (very likely sleep).

4. **Grants are sorted highest → lowest probability** so you only need to
   review the top few hundred candidates — not all 11,400.

## Prerequisites

Python 3.10+ is required. All dependencies are listed in `requirements.txt`.

Install them with one command (run from the **repo root**):

```bash
pip install -r analysis/requirements.txt
```

> The `sentence-transformers` package will download the model (~80 MB) on first
> use. Subsequent runs use the cached model.

---

## Running the pipeline

Run all four scripts **in order** from the **repo root** directory:

```bash
python analysis/01_prepare_data.py
python analysis/02_generate_embeddings.py
python analysis/03_train_and_evaluate.py
python analysis/04_score_and_rank.py
```

Each script prints progress to the terminal and tells you what to run next.

---

## Scripts

| Script | What it does |
|---|---|
| `01_prepare_data.py` | Merges `data/dataset.csv` with `data/manual-selection.csv`. Assigns confirmed "no" labels to all 2020–2026 grants not in the manual-selection file. Outputs `labelled.csv` (~13,000 rows) and `unlabelled.csv` (~11,400 rows for 2014–2019). |
| `02_generate_embeddings.py` | Converts every grant summary to a 384-dimensional embedding using `all-MiniLM-L6-v2`. Saves `.npy` files to `embeddings/`. This is the slow step (~5–10 min for 25,000 grants). **Only needs to run once.** |
| `03_train_and_evaluate.py` | Trains a balanced logistic regression classifier with 5-fold cross-validation on ~13,000 labelled grants. Saves a performance report, a Precision–Recall curve, and the trained model. |
| `04_score_and_rank.py` | Applies the classifier to the 2014–2019 grants. Exports `results/ranked_candidates.csv` sorted by predicted probability (highest first). |

## Manual review workflow

After running step 4, open `results/ranked_candidates.csv` in Excel (or any
spreadsheet application).

The file is sorted by `P_sleep` (highest first). Work from the top:

1. Read each grant summary.
2. Fill in the `Manual_Sleep_Topic` column: `yes` or `no`.
3. Stop when you have gone approximately **50 consecutive grants** without
   finding a genuine sleep grant — at that point the probability of missing
   any further positives is very low.

---

## Active learning (optional improvement)

After completing the manual review:

1. Add the newly labelled grants to `data/manual-selection.csv`.
2. Re-run steps 1, 3, and 4 (step 2 only needs repeating if the dataset changed):

   ```bash
   python analysis/01_prepare_data.py
   python analysis/03_train_and_evaluate.py
   python analysis/04_score_and_rank.py
   ```

3. Check whether the updated model surfaces any additional candidates.

One round is usually sufficient given the strength of the training set.

## Methods summary (for a paper)

> Grants from 2020–2026 (n ≈ 13,000) were used as a labelled training set.
> Grants matching no sleep-related keywords were treated as confirmed
> non-sleep (n ≈ 12,900); grants that matched one or more keywords were
> manually reviewed, yielding 74 confirmed sleep-related and 123 confirmed
> non-sleep grants. Grant summaries were embedded using the
> `all-MiniLM-L6-v2` sentence-transformer model (384 dimensions). A logistic
> regression classifier with balanced class weights was trained on these
> embeddings using 5-fold stratified cross-validation. The classifier was
> then applied to grants from 2014–2019 (n ≈ 11,400), and candidates were
> ranked by predicted probability of being sleep-related. Grants were
> reviewed manually in descending rank order until no further positives
> were identified.

## Key assumptions

- All 2020–2026 grants not in `manual-selection.csv` passed the keyword
  filter with zero matches and are treated as confirmed non-sleep. This is
  the information you provided: only keyword-matched grants were forwarded
  for manual review.
- The training labels are considered ground truth.
- The `all-MiniLM-L6-v2` model runs locally and requires no API key.
  It does not require an internet connection after the initial download.
- The prevalence of sleep grants in 2014–2019 is assumed to be similar to
  2020–2026 (~0.6%), implying approximately 70 sleep grants exist in the
  prediction set.
